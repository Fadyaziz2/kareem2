# 🏛️ عقودي (Oqoody) - لوحة التحكم الإدارية والتحكيم القانوني

لوحة تحكم إدارية إنتاجية متكاملة (Production-Ready Web Admin Dashboard) لمنصة **عقودي (Oqoody)** للوساطة والتوثيق القانوني وحسابات الضمان المالي المشروط (Escrow).

---

## 🎨 الهوية البصرية ونظام الألوان (Design System)
تم بناء واجهة المستخدم بنظام فاخر يجمع بين الزمرد الداكن والذهب الملكي:
* **الخلفية الرئيسية:** Deep Dark Emerald (`#081810`)
* **القوائم والبطاقات السطحية:** Rich Emerald (`#0D2818` و `#133827`) مع حواف ذهبية وزمردية ناعمة (`#1B4D3E`)
* **اللون الذهبي الملكي للعمليات والأزرار النشطة:** Royal Metallic Gold (`#D4AF37`)
* **النصوص والطباعة:** Crisp Off-White (`#F4F6F5`) للعناوين، و Muted Sage (`#A0B2A6`) للنصوص الفرعية بخط جوجل المعتمد **Cairo**.
* **شارات الحالة:** Emerald Green (`#10B981`) للاعتماد والتحرير، Amber (`#F59E0B`) للانتظار، Crimson (`#EF4444`) للنزاعات والرفض.
* **تخطيط عربي كامل:** Full RTL (`dir="rtl"`, `lang="ar"`).

---

## 🚀 التقنيات المستخدمة (Tech Stack)
* **Framework:** React 18 + Vite + TypeScript
* **Routing:** React Router v6 (SPA)
* **Styling:** Tailwind CSS + Custom Emerald Glassmorphism & Gold Glow Effects
* **Icons:** Lucide React Icons
* **Analytics & Charts:** Recharts (AreaChart, PieChart, Custom Tooltips)
* **API Integration:** Axios مهيأ مسبقاً مع JWT Bearer Interceptor والربط مع `http://localhost:5000/api` (أو المتغير `VITE_API_BASE_URL`) مع نظام حماية ذكي احتياطي (Transparent In-Memory Fallback) لضمان التصفح التفاعلي الكامل حتى في حالة عدم تشغيل خادم الباك إند.

## 📦 الصفحات والوحدات التشغيلية (All 9 Modules)

1. **المصادقة والأدوار (`/login`):**
   * بطاقة زجاجية فاخرة تتوسط الشاشة مع شعار ميزان العدالة الذهبي الخاص بمنصة عقودي.
   * إمكانية الدخول بالبريد أو الهاتف وكلمة المرور مع دعم أدوار الإدارة (`super_admin`, `dispute_agent`, إلخ).
   * أزرار للدخول التجريبي السريع بنقرة واحدة (Quick Demo Credentials).

2. **الرئيسية والتحليلات الشاملة (`/`):**
   * 4 بطاقات KPI علوية: إجمالي المستخدمين، المحامين المعتمدين، صفقات الضمان النشطة مع رصيد الخزينة المحتجز، والنزاعات المفتوحة.
   * رسم بياني تحليلي لنمو الإيرادات الشهرية والسيولة المالية (AreaChart).
   * رسم بياني دائري لتوزيع حجم العمليات (الوساطة 55%، الاستشارات 25%، نماذج العقود 20%).
   * ويدجت التنبيهات العاجلة: طلبات اعتماد المحامين العاجلة والنزاعات المفتوحة بغرفة التحكيم.

3. **إدارة المستخدمين والأعضاء (`/users`):**
   * جدول بيانات متقدم للعملاء والمديرين مع بحث فوري وفلترة بالرتبة (`client`, `lawyer`, `dispute_agent`, `super_admin`).
   * نافذة تعديل الرتب والصلاحيات الإدارية فورياً.
   * نافذة تسوية وشحن/خصم أرصدة المحافظ بالجنيه المصري.
   * تفعيل/تعطيل وتوثيق الحسابات بنقرة واحدة.

4. **دليل وتوثيق المحامين (`/lawyers`):**
   * عرض بيانات القيد بالنقابة، درجة التقاضي (`ابتدائي`، `استئناف`، `نقض`)، والتخصصات والتقييم.
   * **نافذة الفحص والمراجعة:** معاينة صور كارنيه النقابة والبطاقة الشخصية، ضبط نسبة عمولة المنصة (الافتراضي 15%)، وأزرار **الاعتماد (`approved`)** أو **الرفض (`rejected`)** مع تدوين سبب الرفض.

5. **محرر ونماذج العقود الذكية (`/templates`):**
   * تصفح النماذج مصنفة حسب المجالات (عقود مالية، تكنولوجيا، عقارات، شركات).
   * **Smart Template Builder:** محرر بنود قانونية متكامل يتيح إدراج الحقول المتغيرة تلقائياً بنقرة زر (مثل `{{اسم_الطرف_الأول}}`, `{{قيمة_العقد}}`, `{{الرقم_القومي}}`, `{{تاريخ_اليوم}}`).
   * ضبط تسعير النموذج وتفعيل شرط مراجعة المحامي البشري.
   * معاينة النص الكامل للعقد وحذف النماذج.

6. **مراقبة الاستشارات القانونية (`/consultations`):**
   * فلترة حسب نوع الاستشارة (مكتوبة، مكالمة هاتفية، زيارة مكتب) والحالة.
   * عرض تفاصيل ومذكرات المحامي والمرفقات.
   * **إعادة توجيه الاستشارة:** قائمة منسدلة بالمحامين المعتمدين لإسناد الاستشارة لمحامٍ آخر.

7. **إدارة الوساطة وحساب الضمان Escrow (`/escrow`):**
   * متابعة صفقات الدفع المشروط بين الطرف الأول والثاني، الإجمالي، ورابط وثيقة العقد الموقعة.
   * درج تفصيلي لمراحل الدفع والإنجاز (Milestones) مع نسب ومبالغ وشروط كل مرحلة.
   * **تحكم إداري استثنائي:** تحرير فوري للدفعة إدارياً (`Force Release`) أو تجميد العملية بالكامل لحين فض النزاع (`Freeze/Unfreeze`).

8. **غرفة التحكيم وفض النزاعات (`/disputes`):**
   * واجهة غرفة التحكيم المنقسمة (Split Screen):
     * القائمة الجانبية: القضايا المفتوحة ودرجات الأولوية (عاجل جداً، مرتفع).
     * المنصة الرئيسية: وقائع النزاع، المستندات والأدلة المصورة، وتدوين أسباب الحكم.
     * **أزرار الحكم التنفيذي الملزم:**
       1. استرداد 100% للمشتري (الطرف الأول).
       2. تحرير 100% للمنفذ (الطرف الثاني).
       3. تسوية وتقسيم مخصص بنسب مرنة وتحديث المحافظ فورياً.

9. **المالية والتحويلات (`/financials`):**
   * مؤشرات صافي إيرادات المنصة وحجم صفقات الضمان ومبالغ الأرباح المعلقة والمكتملة.
   * جدول طلبات سحب أرباح المحامين مع أزرار الموافقة والتحويل البنكي الفوري عبر الـ IBAN.
   * سجل قيود وعمولات المنصة (Ledger).
   * زر لتصدير التقارير المالية بصيغة CSV.

## 🛠️ خطوات التشغيل السريع (Quick Start)

### 1. الدخول لمجلد لوحة التحكم وتثبيت الحزم (إن لم تكن مثبتة):
```bash
cd admin_dashboard
npm install
```

### 2. تشغيل السيرفر المحلي على البورت 3000:
```bash
npm run dev
```
سيتم فتح لوحة التحكم على:
👉 **`http://localhost:3000`**

### 3. بناء نسخة الإنتاج وفحص الأنواع (Type-Check & Build):
```bash
npm run build
```
*(تم التحقق والتأكد من نجاح البناء بنسبة 100% وخلوّه من أي أخطاء)*.

## 🔗 نقاط النهاية في الـ Backend المتصلة باللوحة

* `POST /api/auth/login` - تسجيل دخول المشرفين
* `GET /api/admin/dashboard-stats` - إحصائيات لوحة التحكم والرسوم البيانية
* `GET /api/admin/users` - جلب المستخدمين وفلترتهم
* `PATCH /api/admin/users/:id/role` - تعديل الرتبة
* `PATCH /api/admin/users/:id/toggle-status` - تفعيل/تعطيل الحساب
* `PATCH /api/admin/users/:id/wallet` - تسوية رصيد المحفظة
* `GET /api/lawyers` & `PATCH /api/lawyers/:id/verify` - دليل واعتماد المحامين
* `GET /api/templates`, `POST /api/templates`, `PUT /api/templates/:id`, `DELETE /api/templates/:id` - محرر العقود
* `GET /api/consultations` & `PATCH /api/consultations/:id/reassign` - الاستشارات
* `GET /api/escrow`, `PATCH /api/escrow/:id/milestones/:mId/release`, `PATCH /api/escrow/:id/freeze` - الوساطة
* `GET /api/disputes` & `PATCH /api/disputes/:id/resolve` - غرفة التحكيم
* `GET /api/admin/financials` & `POST /api/admin/financials/withdrawals/:id/approve` - المالية وسحب الأرباح
* `POST /api/admin/seed` - زراعة بيانات تجريبية واقعية متكاملة في MongoDB
